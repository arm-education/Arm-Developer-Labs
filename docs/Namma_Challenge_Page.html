Programme Overview

The Namma Smart AI Apps Challenge is a national initiative from Arm and IIIT Bangalore, supported by NASSCOM, that helps participants build practical skills in Edge AI application development on edge devices.

The challenge is open to both students (UG/PG) and working professionals & developers, reflecting the breadth of Edge AI application-development talent across academia and industry.

The programme has a strong focus on skill development and provides project-based learning opportunities for all participants.

Participants will build real-world applications with societal impact across healthcare, education, telemedicine, gaming, and application modernisation, with mentorship from Arm engineers and IIIT Bangalore faculty.

Programme Objectives

  • Build practical, industry-relevant skills in AI and application development on edge devices.
  • Develop real-world applications that address genuine societal challenges.
  • Gain hands-on experience in optimisation, benchmarking and deployment.
  • Learn directly from Arm engineers and IIIT Bangalore faculty through structured mentorship.
  • Gain experience working at the intersection of academic learning and industry engineering.
  • Strengthen practical understanding of Edge AI development on Arm-based platforms.

Technology Theme

AI-Native Smart Applications for Digital Karnataka

Artificial Intelligence is moving from the cloud to the edge. The challenge invites participants to develop intelligent, secure, responsive applications capable of operating efficiently on local devices.

  • Windows on Arm
  • ONNX Runtime
  • Arm SME2 (Scalable Matrix Extension 2)
  • KleidiAI

The goal is high-performance, privacy-preserving applications with fast on-device inference, improved power efficiency, responsiveness, and reduced dependence on continuous connectivity.

What Makes This Challenge Different

This is an Edge AI challenge rather than a traditional cloud-only hackathon. Participants build AI-native on-device applications designed for privacy, low latency, responsiveness, offline capability, and power efficiency.

Real-world societal challenge areas are paired with mentorship from Arm and academic guidance from IIIT Bangalore. Students and working professionals gain hands-on experience in building, optimisation, benchmarking, and deployment.

In Phase 1, all registered participants submit a project report containing:

Clear articulation of the chosen challenge and proposed solution approach.
Technical Architecture
System design, model selection and Arm backend selection.
Working Code Repository
A public or shared GitHub repository with runnable code, README, setup instructions and at least a basic working prototype.
Performance Baseline
Initial benchmarking results or projections for on-device latency, memory footprint and accuracy.
Demo Video
A 3–5-minute video demonstrating the working prototype.

Project Challenge Areas

1. AI Consultation Preparation Assistant for Patients Domain: Healthcare

Domain: Healthcare
Applicable for: Students

In Karnataka's Tier-2 and Tier-3 towns and rural taluks, patients accessing online consultations can struggle to organise symptoms, medical history, prescriptions, reports and questions before a consultation, particularly when the consultation is in English and the patient is more comfortable in Kannada or any other Indian language.

Build an Arm64-native consultation-preparation application that uses AI to transform patient-provided notes and documents into a patient-friendly summary, relevant questions for the doctor and a consultation checklist, with Kannada or any other Indian language as a core experience.

Disclaimer: This solution is intended solely as a prototype/proof of concept for development, research and demonstration purposes. It is not medically validated, certified or approved and must not be used for diagnosis, treatment, clinical decision-making or real-world patient care.

The solution should prioritise privacy-conscious processing, useful offline/local workflows where feasible, and efficient Arm64 execution.

Students may develop, test and demonstrate the solution using the free Azure account and B2pts v2 Arm-based burstable VM allocation (up to 750 hours/month).

Physical WoA hardware, NPU access and SME2 are not prerequisites.

Teams should document which parts run locally on the Arm VM, any cloud services used, latency and resource usage, and how the architecture could map to a future Windows on Arm client.

Teams are encouraged to use ONNX Runtime for deploying and running AI models efficiently on Arm64 and explore Arm KleidiAI integration/optimisations, where applicable, to build an Arm-optimised AI software stack.

The Azure Arm64 VM can be used for development, model conversion, compilation, functional validation, inference and performance/resource analysis.

Teams should document:

  • AI models and runtimes used
  • ONNX Runtime/KleidiAI integration where applicable
  • components running locally on the Arm VM
  • any external cloud services used
  • latency and resource utilisation
  • how the architecture could subsequently map to a Windows on Arm client
  • potential path to SME2-based optimisation on compatible hardware
